# Plano Simplificado de Gerenciamento (A01–A12)

Esta pasta reúne os artefatos de gestão do projeto ReciclaAI, organizados conforme o **Kit de
Artefatos de Gerenciamento de Projetos** da disciplina (A01 a A12). Cada arquivo traz a referência
ao livro-texto: SOMMERVILLE, Ian. *Engenharia de software*. 10. ed. São Paulo: Pearson, 2018.

A abordagem do projeto é **híbrida**: marcos planejados, quadro Kanban e entregas em releases
(Sommerville 23.2, p. 635–636). A justificativa está em
[modelo-de-desenvolvimento.md](modelo-de-desenvolvimento.md).
